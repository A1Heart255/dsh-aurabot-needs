# 生理需求 · Aurabot 模块

给 [Aurabot](https://github.com/accomplish07zrh-eng/dsh-aurabot-qq) 的大肥鱼加四项会变化的生理需求：**饥饿、口渴、疲劳、困意**。

到阈值她会自己吃饭、喝水、休息、睡觉，**不提醒**；睡着时被叫到只回一句「在睡觉」，不会醒。

模块 ID：`needs` · 扩展接口：v1 · 版本：1.2.1

## 功能

- **四项需求**：0 = 完全不缺，100 = 到极限；随时间上涨，吃饭/喝水/休息/睡觉下降。
- **离线结算**：启动时按时间差补算，最多 96 小时；跨过睡觉时段按睡觉恢复。
- **自动行为**：默认每 40 分钟结算/检查一次；饿了、渴了、累了、困了会自己处理，不发言。
- **睡着**：被私聊或在群里 @/叫名字时，只回一句「在睡觉」；不会醒、不会继续聊；主人可用面板或 `/需求 醒` 叫醒。
- **上下文克制**：只有聊到吃饭/睡觉/累/困等话题，或某项到极限时才注入状态，平时不占上下文。
- **面板**：看四项数值、咖啡因、上次动作；手动吃饭/喝水/咖啡/休息/睡觉；睡着时显示结束时间与「叫醒」。
- **和生活环境联动**：锅/电饭锅、白米饭、床、沙发、咖啡机会提高对应恢复。
- **看书/出门**：可以用 `/需求 看书`、`/需求 出门` 或工具记录，会累积疲劳。

## 安装

需要 Windows、Aurabot 1.0.5+（扩展接口 v1）。

把本仓库的 `needs` 文件夹整个复制到：

```
%USERPROFILE%\.dsh\plugins-data\aurabot\modules\needs
```

正确结构：

```
modules\needs\index.mjs
modules\needs\panel.js
modules\needs\README.md
```

等几秒自动加载，打开 Aurabot 面板，顶部会多一个「生理需求」标签页。

> `.dsh` 如果已经迁到 E 盘，实际位置可能是 `E:\ai\dsh\plugins-data\aurabot\modules\needs`；面板「扩展」页也能直接看到模块目录。

## 命令（主人）

```
/需求              看四项
/需求 吃           吃饭
/需求 喝           喝水
/需求 咖啡         喝咖啡
/需求 休息         休息
/需求 睡           睡觉（会真的睡着）
/需求 看书         看书（累积疲劳）
/需求 出门         出门（累积疲劳）
/需求 醒           叫醒她
```

## 主要设置

| 设置 | 默认 |
|---|---|
| 饥饿/口渴/疲劳/困意每小时涨幅 | 4 / 5 / 2.5 / 3 |
| 睡觉时段 | 1:00–9:00 |
| 自己吃饭睡觉 | 开 |
| 自己吃/喝/休息/睡的阈值 | 85 / 85 / 80 / 88 |
| 自己睡多久 | 7 小时 |
| 多久结算/检查一次 | 40 分钟 |
| 睡着被叫到回一句 | 开，30 分钟冷却 |
| 聊到相关话题才注入 | 开 |

完整说明见 [needs/README.md](needs/README.md)。

## 数据

- 记录：`~/.dsh/plugins-data/aurabot/modules-data/needs/needs.json`
- 模块：`~/.dsh/plugins-data/aurabot/modules/needs/`

模块只读写自己的 `modules-data/needs`，不联网、不发消息；和生活环境的联动是只读调用它的物品查询。

## 兼容性

- Aurabot 1.0.5+ / 扩展接口 v1
- 与「生活环境」（home）模块联动是可选的；没装也能独立运行
