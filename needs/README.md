# 生理需求（Aurabot 扩展模块）

给大肥鱼加四项会随时间变化的生理需求：饥饿、口渴、疲劳、困意。到阈值她会自己吃饭、喝水、休息、睡觉，**不提醒**；睡着期间被叫到只回一句「在睡觉」，不会醒。

四项统一成「需求强度」：`0 = 完全不缺，100 = 到极限`。这样面板、阈值和「饿/渴/累/困到什么程度」不会搞反。

## 怎么变

- **饥饿**：随时间上涨，吃饭下降；家里有电饭锅/锅、白米饭会降得更多。
- **口渴**：随时间上涨，喝水下降；咖啡也会解一点渴。
- **疲劳**：随时间上涨，聊天/回复会自动累积；看书、出门可以用面板/工具记一笔（也会累）；休息、睡觉下降；家里有床/沙发会恢复更多。
- **困意**：随时间上涨，夜里涨得快；咖啡因会暂时压低（面板显示的是压过之后的困意），咖啡因代谢掉之后会反弹；睡觉下降。
- **离线结算**：模块启动时按上次时间差补算，最多补 96 小时；跨过睡觉时段（默认 1:00–9:00）的部分按睡觉恢复疲劳/困意，饥饿/口渴照常涨。

## 什么时候影响她说话

- 只有你聊到「吃 / 饭 / 饿 / 喝 / 水 / 渴 / 咖啡 / 睡 / 困 / 累 / 休息 / 熬夜 / 起床 / 白米饭 / 床 / 沙发」这些词，才会把当前四项状态塞进她的上下文；
- 某一项到「到极限」（默认 85）时，即使没聊到也会提醒她；
- 平时不占上下文，也不会主动报数值；
- 她可以用工具 `needs_look` 看自己、`needs_act` 吃饭/喝水/咖啡/休息/睡觉/看书/出门。

## 会自己吃饭睡觉吗

会，默认开着，但**不提醒**：

- 默认每 40 分钟结算/检查一次（可调 5–240 分钟）；数值仍按真实时间算，不会少算；
- 饿 ≥ 85 自己吃，渴 ≥ 85 自己喝，累 ≥ 80 自己休息；
- 困 ≥ 88（夜里提前到 73）且连续 10 分钟没人聊天，自己睡；
- 睡觉时长默认 7 小时；
- 睡着期间：被叫到会回一句「在睡觉」（私聊直接回，群里 @/叫名字才回），但不会继续聊、也不会醒；
- 同一聊天默认 30 分钟最多回一次，防刷屏；
- 只能通过面板「叫醒她」或 `/需求 醒` 叫醒；
- 自动行为只改状态，不会发「我去吃饭了」这种消息。

## 面板

Aurabot 顶部的「生理需求」标签页：

- 四项进度条 + 状态文字
- 咖啡因、上次动作、上次结算
- 手动按钮：吃饭 / 喝水 / 喝咖啡 / 休息 / 睡觉
- 睡着时显示睡眠结束时间，其他按钮禁用，只留「叫醒她」
- 自动行为开关和阈值在设置里；面板会显示当前自动规则
- 家里有锅/白米饭/床/沙发/咖啡机会显示加成

## 命令

```
/需求              看四项
/需求 吃           吃饭
/需求 喝           喝水
/需求 咖啡         喝咖啡
/需求 休息         休息
/需求 睡           睡觉（会真的睡着，被叫到只回一句在睡觉）
/需求 看书         看书（累积疲劳）
/需求 出门         出门（累积疲劳）
/需求 醒           叫醒她
```

## 和生活环境联动

- 吃饭：家里有「电饭锅/电饭煲/锅」+8，有「白米饭/米饭/大米/米」+8
- 睡觉：家里有「床」+8
- 休息：家里有「沙发/抱枕/躺椅」+6
- 咖啡：家里有「咖啡机/咖啡壶」+8 咖啡因

「生活环境」没开或没装时，这些加成自动跳过。

## 边界

- 自动睡觉会真的进入睡眠：被叫到只回一句在睡觉（群聊要 @ 或叫名字），不会继续聊，只能面板或 `/需求 醒` 叫醒。
- 自动行为不提醒；饿了/困了她不会主动发消息说。
- 睡着期间饥饿/口渴仍会在醒来时补一点，但不会在睡眠中打扰她。
- 困意显示的是「减去咖啡因压制之后」的值；咖啡因代谢掉后会反弹。
- 四项都是需求强度，越高越缺；不是「饱腹度/体力值」那种越高越好的条。
- 只有聊到相关话题或到极限才注入，不会每轮都占上下文。
